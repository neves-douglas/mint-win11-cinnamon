# Origem dos arquivos

Este pacote junta o visual montado no Linux Mint Cinnamon (tema Win11 + ícones bloom + pastas Fluent).

| Peça | Origem | Licença |
| --- | --- | --- |
| Tema GTK/Cinnamon `Win11-round-Dark` | [vinceliuice/Win11-gtk-theme](https://github.com/vinceliuice/Win11-gtk-theme) (`--tweaks round square`) | GPL-3.0 |
| Pastas amarelas Win11, lixeira, Explorer | [yeyushengfan258/Win11-icon-theme](https://github.com/yeyushengfan258/Win11-icon-theme) | GPL-3.0 |
| Ícones da sidebar do Nemo | [vinceliuice/Fluent-icon-theme](https://github.com/vinceliuice/Fluent-icon-theme) | GPL-3.0 |
| Tema de ícones `bloom` / `bloom-dark` | Deepin Icon Theme (já presente em `/usr/share/icons/bloom` nesta máquina) | GPL |
| Fallback de ícones | [Papirus](https://github.com/PapirusDevelopmentTeam/papirus-icon-theme) | GPL-3.0 |
| Wallpaper de desktop | wallpaper oficial Windows 11 dark (stock). Substitua se não quiser usar o arquivo da Microsoft. | © Microsoft |
| Wallpaper do login | recorte/adaptação no mesmo estilo, em `assets/greeter/` | — |

O CSS do Nemo, os tamanhos do painel/menu e o layout da barra são configuração local deste desktop.
