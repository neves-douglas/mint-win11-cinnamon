COMO INSTALAR (Linux Mint Cinnamon)
===================================

Jeito mais fácil
----------------
1. Abra a pasta mint-win11-cinnamon
2. Clique duas vezes em "Instalar.desktop"
3. Se o Mint perguntar, escolha "Executar no terminal"
4. Digite a senha do computador (não aparece asterisco, é normal)
5. Espere terminar (no final o próprio instalador recarrega o painel
   e mostra: se não mudou, Alt+F2, digite r, Enter)

Pelo terminal
-------------
  chmod +x install.sh
  ./install.sh

O script instala sozinho:
  - ícones bloom (pacote deepin-icon-theme)
  - Papirus
  - cursor Yaru
  - tema das janelas
  - pastas amarelas Win11
  - painel 60px / ícones 38px (mesma barra, sem os programas pessoais)
  - menu Iniciar
  - Win+L trava a tela (como no Windows)
  - wallpaper
  - tela de login

Precisa de internet na primeira vez (baixa o bloom, ~31 MB).
